# UBL 2.5 — Universal Business Language

A Rust implementation of the UBL 2.5 specification, providing clean domain types for all UBL document types and their common aggregates.

## Structure

-  — Common aggregates, basic components, and shared types
-  — Individual document type modules (Invoice, Order, CreditNote, etc.)
- No adapters yet — pure domain/core modules only.

## Reference

OASIS UBL 2.5 Specification: https://docs.oasis-open.org/ubl/cs01-UBL-2.5/UBL-2.5.html
