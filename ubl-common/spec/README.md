# UBL 2.5 Common Schema (XSD)

Core type definitions for all UBL documents.

## Contents

### CBC — Common Basic Components
- `UBL-CommonBasicComponents-2.5.xsd` — 1,202 type definitions (Amount, Code, Identifier, Date, Text, Quantity, Measure, Indicator, Numeric, Binary)

### CAC — Common Aggregate Components
- `UBL-CommonAggregateComponents-2.5.xsd` — 80 aggregate types (Party, Address, Item, Tax, Price, Delivery, etc.)

### Dependencies
- `BDNDR-CCTS_CCT_SchemaModule-1.1.xsd` — CCTS core component types
- `BDNDR-UnqualifiedDataTypes-1.1.xsd` — Unqualified data types
- `UBL-QualifiedDataTypes-2.5.xsd` — Qualified data types
- `UBL-CommonExtensionComponents-2.5.xsd` — Extension mechanism
- `UBL-ExtensionContentDataType-2.5.xsd` — Extension content

### Signatures
- `UBL-SignatureBasicComponents-2.5.xsd`
- `UBL-SignatureAggregateComponents-2.5.xsd`
- `UBL-CommonSignatureComponents-2.5.xsd`
- `UBL-xmldsig-core-schema-2.5.xsd`
